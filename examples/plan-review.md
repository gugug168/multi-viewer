# Plan Mode 独立审查模板

## 待审计划

把已经写好的计划全文贴在这里。不要只给一句任务标题；审查方需要看到目标、范围、步骤、边界和预期交付物。

## 审查任务

你是独立审查者。请不要重写计划，也不要假设其他审查方已经看过它。请按以下结构输出：

1. **问题**：指出具体缺口、矛盾、未经验证的前提或越权动作；
2. **依据**：说明该问题对应计划中的哪一段、哪项约束或什么可观察事实；
3. **最小修正**：给出能消除问题的最小改动，而不是另起一套大方案；
4. **人工闸门**：明确哪些发布、付款、账号、正式事实或主观取舍不能自动执行；
5. **验收**：指出哪些步骤缺少可观察的完成标准、失败恢复或回滚方式。

重点检查：

- 目标、范围、非目标和成功标准是否可以区分；
- 是否遗漏依赖、输入、权限、数据来源或失败分支；
- 是否把“可能成立”的假设当成“已经确认”的事实；
- 每一步是否有足够的证据和可复核结果；
- 是否存在低成本的删除、简化或分阶段验证机会。
